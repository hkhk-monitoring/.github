# Süsteemide monitooring

Haapsalu Kutsehariduskeskuse IT-kursus

[Kursuse materjalid](https://hkhk-monitoring.github.io/monitoring/) &nbsp;·&nbsp; [Haapsalu Kutsehariduskeskus](https://www.hkhk.edu.ee)

</div>

---

Kuidas süsteem endast räägib ja kuidas seda kuulata: logid, mõõdikud, graafikud ja alarmid.

Iga kohtumine on üles ehitatud labori ümber: töötad oma kolme virtuaalmasinaga, paned püsti monitooringu tööriistad ja esitad töö GitHubis, kus automaatkontroll annab tagasiside iga push'i järel.

## Materjalid

**[Süsteemide monitooring](https://hkhk-monitoring.github.io/monitoring/)**
Logid ja keskne logiserver, Zabbix, Prometheus ja Grafana, aegrea andmebaasid, Loki, OpenSearch

**[Süsteemide monitooring, lühikursus](https://hkhk-monitoring.github.io/monitoring-lite/)**
Mõõdikud, graafikud, alarmid ja logid
